# Security Policy

CaYaRouter is experimental research software for local network hardware.

## Reporting a vulnerability

Do not publish modem credentials, configuration backups, firmware dumps, serial numbers, MAC addresses, Wi-Fi keys, ISP credentials, or private recovery data in public issues.

Report security-sensitive findings privately to the repository owner through GitHub's private vulnerability reporting feature when available.

## Operational safety

- Test only on hardware you own or are authorized to manage.
- Keep a verified recovery image and configuration backup before experiments.
- Do not expose the modem management interface to the public internet.
- Do not flash experimental images without a verified bootloader recovery path and full flash backup.
- Treat generated configuration backups and authenticated captures as secrets.
